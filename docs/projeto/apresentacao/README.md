# Apresentação no Overleaf

Esta pasta é autocontida. Para usar:

1. Crie um projeto vazio no Overleaf.
2. Envie os cinco arquivos desta pasta para a raiz do projeto.
3. Defina `main.tex` como documento principal.
4. Compile com pdfLaTeX.

Arquivos necessários:

- `main.tex`
- `mean_turnaround_ic95.png`
- `jain_slowdown_pct_ic95.png`
- `context_switches_ic95.png`
- `comparativo_convergencia_ic95.png`

O roteiro de fala, com responsáveis e divisão exata dos dez minutos, permanece em `../apresentacao.md` no repositório.
